Frozen 2025 temporal test

Frozen Jan–Dec 2025 retrospective hindcast, n=12. Model MAE 0.325 °C and monthly-climatology MAE 0.166 °C; paired MAE difference +0.159 °C (0/12 months lower absolute error for the model). Observed interval coverage was 83.3% (10/12), with mean width 1.161 °C. These 12 months provide a low-precision descriptive result.

Inputs use rolling T-14 through T-3 histories, strictly before each target month; realized 2025 observations may serve as past inputs for later 2025 targets. Contemporaneous NASA release timestamps were not established, so this is labeled a retrospective hindcast. The model and interval choice were frozen before the target data were opened; no model selection used this test.
